# Degustation · Дегустационный лист

Android-приложение для личных и групповых дегустаций на одном устройстве. Русский интерфейс, работа без регистрации и интернета. Телефоны, планшеты и Android TV / Google TV на Android 8.0 и новее с работающим системным WebView.

## Возможности

- Сеты с ручным добавлением вин, импортом CSV и выбором уже существующих карточек из общей коллекции.
- Собственный номер образца для каждого сета; номера редактируются в настройках сета. Активная групповая сессия фиксирует состав образцов.
- Списки всех, оценённых и неоценённых вин; сортировка по номеру, названию, убыванию и возрастанию баллов; поиск по названию и номеру.
- Несколько оценщиков. Личный режим позволяет оценить любое вино из любого сета; групповой режим объединяет участников вокруг одного выбранного сета.
- Слепой лист с одним номером или открытый лист с названием. Три листа на 100 баллов: OIV 2025 для тихих, OIV 2025 для игристых, классический OIV для тихих.
- Автоматическая сумма, обязательное заполнение каждого критерия, комментарий, отметка дефекта и автосохранение черновика.
- Неограниченные повторные оценки с отдельными датами, авторами и детализацией критериев. Дата не позднее текущей и не раньше урожая.
- Отдельная страница результатов, первые три места, прогресс участников и выгрузка сводной / подробной таблицы CSV.
- Карточка вина: производитель, урожай, дата розлива, магазин, цена, заметки, фото из галереи или камеры; минимум, максимум, среднее, история и график по датам / оценщикам.
- Сравнение вин одного названия разных лет с фильтрами дат и оценщика, графиком и возрастом на дату дегустации.
- Полная резервная копия JSON с фотографиями и восстановлением на другом устройстве.
- Пульт Android TV: стрелки, OK, «Назад», крупный шрифт и видимый фокус, отдельный баннер для TV Launcher.

## Установка

Откройте `output/Degustation-1.0.0.apk` на устройстве и разрешите установку приложений выбранному файловому менеджеру. На телевизоре передайте APK через USB, файловый менеджер или `adb install -r Degustation-1.0.0.apk`. Иконка появляется и в обычном, и в телевизионном лаунчере. Для обновления нужен APK с тем же applicationId и ключом подписи.

Для камеры используется установленное приложение камеры. Для выбора и сохранения файлов — системный выбор документов. Если на TV нет приложения выбора документов, Android 10+ пытается сохранить экспорт в `Загрузки/Degustation`. Импорт и камера требуют соответствующих приложений на конкретном устройстве. Разрешения на интернет и общий доступ к хранилищу не запрашиваются.

## Начало работы

1. Выберите личную дегустацию или дегустацию в компании.
2. Создайте сет, добавьте вина вручную, из CSV или общей коллекции. В пустой коллекции можно отдельно загрузить вымышленный учебный пример.
3. Для группы сначала добавьте оценщиков; при начале выберите минимум двоих, дату, лист и слепой/открытый показ.
4. Нажмите «Оценить», выберите имя оценщика и номер образца. Заполните строки листа и нажмите «Отправить».
5. Передайте устройство следующему участнику или откройте результаты. Сохраняйте полную копию в настройках перед переносом устройства или удалением приложения.

Подробно: [CSV](docs/CSV.md), [методика подсчёта](docs/SCORING.md), [архитектура](docs/ARCHITECTURE.md), [проверки](docs/VALIDATION.md).

## Проект и сборка

`app/src/main/java` — нативная оболочка Java; `app/src/main/assets` — весь интерфейс и модель данных; `app/src/main/res` — ресурсы Android; `samples` — пример CSV; `tests` — тесты; `scripts` — сборка; `.github/workflows/android.yml` — GitHub Actions.

Основной проверенный путь сборки — официальный Android SDK без Gradle и внешних библиотек приложения:

```bash
sdkmanager 'platforms;android-35' 'build-tools;35.0.0'
export ANDROID_HOME=/path/to/Android/Sdk
node tests/core.test.cjs
bash scripts/build-apk.sh
```

Нужны JDK 17+, Python 3, zip и Android SDK. Если доступна только JRE, сборщик принимает `ECJ_JAR=/path/to/ecj-3.39.0.jar`. Используется официальный Eclipse Java Compiler из Maven Central. Инструменты SDK и JDK в репозиторий не входят.

Для Android Studio: откройте корень проекта, выберите JDK 17+ и SDK 35; `./gradlew assembleDebug` использует Gradle 8.11.1 и AGP 8.9.2. Полученный debug APK подписывается стандартным ключом Android Studio и не обновляет отдельно подписанный APK из поставки. `assembleRelease` в Gradle создаёт неподписанный APK; для подписанного установочного файла используйте `scripts/build-apk.sh` или собственную signingConfig.

Сборщик при первом запуске создаёт **закрытый ключ подписи** в `work/signing`. Эти файлы игнорируются Git. Для последующих обновлений сохраните `degustation.jks` и `password.txt` в защищённом месте. Для сборки с сохранённым ключом задайте `DEGUSTATION_SIGN_DIR` на папку, содержащую оба файла. CI без подключённого постоянного ключа создаёт новый тестовый ключ на каждый запуск; такие APK устанавливаются начисто, а не обновляют поставку.

В архиве исходников нет закрытого ключа и пользовательских данных. Отдельный архив `Degustation-signing-private.zip`, если выдан вместе с APK, содержит ключ именно этого APK; храните его приватно и не загружайте в GitHub.

## Проверка интерфейса

```bash
python3 -m pip install playwright
python3 -m http.server 8765 --directory app/src/main/assets --bind 127.0.0.1
# Во втором терминале, с Chromium в /usr/bin/chromium:
python3 tests/ui_test.py
python3 tests/management_test.py
```

Переменная `CHROMIUM` задаёт другой путь к установленному Chromium. Браузерный режим предназначен для разработки и тестов; на Android данные сохраняет нативная оболочка через AtomicFile.
