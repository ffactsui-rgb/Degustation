# Размещение проекта на GitHub

Целевой репозиторий: `ffactsui-rgb/Degustation`.

Если репозиторий ещё не создан, создайте пустой `Degustation` в своём профиле. Не добавляйте начальные README / .gitignore, если будете отправлять локальную историю целиком.

На своём компьютере с авторизованным GitHub CLI можно выполнить `bash scripts/publish-github.sh`: скрипт создаст приватный репозиторий, отправит исходники и прикрепит APK к выпуску v1.0.0. Для этого положите предоставленный APK в папку `output/`. Закрытый ключ подписи никогда не загружается.

Или после распаковки исходников отправьте проект вручную:

```bash
git init -b main
git add .
git commit -m 'Create Degustation Android application'
git remote add origin https://github.com/ffactsui-rgb/Degustation.git
git push -u origin main
```

Папки `work/` и `output/`, а также закрытые ключи подписи исключены из Git. Включён workflow `.github/workflows/android.yml`: тесты модели, сборка подписанного тестового APK и артефакт `Degustation-APK`. Для выпусков с возможностью обновления используйте постоянный ключ подписи (см. README). APK из исходной поставки можно дополнительно прикрепить к GitHub Release вручную.

Подключённый инструмент GitHub текущей сессии поддерживает работу с файлами существующих репозиториев, но не создание репозиториев. Прямой API GitHub из среды блокируется сетевой политикой. До появления репозитория исходники и установочный APK сохраняются локально и выдаются отдельно.
