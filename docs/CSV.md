# Импорт и экспорт CSV

Откройте сет → «Добавить вино» → «Загрузить вина из CSV». Приложение покажет предпросмотр и добавит все строки после нажатия кнопки. Если в файле есть ошибка, не добавляется ни одна строка.

Поддерживаются UTF-8 (включая BOM) и Windows-1251, разделители `;`, `,` и табуляция, кавычки, удвоенные кавычки и переносы строк внутри полей. В Android кодировка определяется при чтении. Рекомендуется UTF-8 и `;`. Максимум 5000 вин и 20 МБ на один импорт.

| Заголовок | Русский вариант | Значение |
|---|---|---|
| `number` | Номер | Уникальный номер образца внутри сета; если пусто, назначается автоматически |
| `name` | Название | Обязательное название вина |
| `producer` | Производитель | Производитель |
| `year` | Год | Год урожая; пусто для вина без года |
| `bottled` | Дата розлива | Дата в формате YYYY-MM-DD |
| `shop` | Магазин | Место покупки |
| `price` | Цена | Число, допускается десятичная запятая |
| `type` | Тип | Например, Тихое или Игристое |
| `notes` | Заметки | Заметки о вине |

Пример — `samples/wines.csv`. Фото добавляются в карточке вина, не через CSV. Импорт создаёт новые карточки вин; чтобы использовать ту же карточку с общей историей, выбирайте «Из коллекции».

Есть три вида экспорта:

1. Итоговая таблица: место, средний, минимальный и максимальный баллы, число оценок и оценщиков.
2. Подробные оценки: каждая попытка, автор, дата, схема, все критерии, комментарий, дефект и идентификатор сессии.
3. Список вин: пригоден для повторного импорта.

Результаты экспортируются для выбранной сессии или для всех оценок сета, включая всех участников этой сессии. Фильтр отдельного оценщика на странице результатов предназначен для просмотра; экспорт включает всех авторов. Формат экспорта: UTF-8 с BOM, `;`, CRLF. Текстовые ячейки, начинающиеся с символов формул, получают защитный апостроф. CSV не восстанавливает дневник целиком: для переноса оценок и фотографий используйте JSON-копию в настройках.
