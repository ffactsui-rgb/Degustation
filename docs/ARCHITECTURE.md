# Архитектура

`MainActivity` — небольшая нативная оболочка Java без сторонних Android-библиотек. Интерфейс HTML/CSS/JavaScript поставляется внутри APK и не загружается из сети. Это устанавливаемое Android-приложение; системный WebView является движком отображения.

- Origin `https://degustation.local` обслуживается исключительно из assets через WebViewClient.
- Все другие адреса блокируются. Доступ к file:// и content:// из WebView отключён. INTERNET permission отсутствует, CSP запрещает сетевые запросы и inline-скрипты.
- JavaScript-интерфейс предоставляет атомарное чтение/запись дневника, выбор документов, экспорт, фото и информацию о TV. Операции с файлами и изображениями выполняются в отдельном потоке.
- Дневник `files/diary-v1.json` записывается `android.util.AtomicFile` в закрытое хранилище приложения; это не cache и не localStorage WebView. Автосохранение срабатывает после каждого критерия, изменения комментария и перед навигацией из листа.
- Состояние проверяется до записи и при восстановлении. Ошибка чтения отключает автоматическую перезапись, чтобы не затереть исходные данные.
- Фото уменьшаются до 1200 пикселей по длинной стороне, поворачиваются по EXIF и сохраняются JPEG в дневнике. JSON-копия переносит и фото. Камера пишет только в один временный файл через неэкспортируемый grant-only ContentProvider.
- Нет паролей, сервера, аналитики и синхронизации. Профили предназначены для совместного использования одного устройства.

## Модель

`users` — оценщики; `wines` — общая коллекция карточек; `sets.entries` — ссылки на вино с номером внутри сета; `ratings` — отдельные попытки с датой, пользователем, вином, сетом, схемой, критериями и суммой; `sessions` — групповые дегустации с фиксированным составом и участниками; `drafts` — незавершённые листы; `settings` — режим, текущий оценщик и активная сессия.

При повторном использовании вина в новом сете сохраняется wineId, поэтому карточка объединяет всю историю. Историческая оценка также сохраняет номер, показанный на момент дегустации. Изменение года/названия карточки намеренно действует на одну общую карточку во всех сетах. Для физически разных образцов с разными урожаями создаются разные карточки.

Групповая сессия хранит собственную копию состава образцов. Нельзя добавить образцы в сет до завершения активной сессии; позже состав сета может расширяться без изменения старых результатов.

## Пределы

До 48 МБ на полный дневник и JSON-файл, до 20 МБ / 5000 строк на один CSV. Фото хранятся в JSON: для больших архивов потребуются регулярный экспорт и дальнейший переход к отдельным файлам/БД. В интерфейсе нет удаления истории или полного сброса; это сознательно сохраняет оценки. Восстановление JSON заменяет дневник после подтверждения.

Требуется актуальный Android System WebView с JavaScript ES2020. На старых устройствах обновите WebView через штатный магазин. При невозможности создать WebView оболочка показывает понятное сообщение. Не все телевизоры оснащены камерой и приложением выбора документов.
