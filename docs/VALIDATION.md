# Проверки версии 1.0.0

Дата: 2 ноября 2026 года.

## Выполнено

- 24 теста модели: максимальная сумма каждого листа, обязательность критериев, повторные оценки, равный вес оценщиков, снимок состава групповой сессии, равные места, отсутствие оценки, дефекты от разных участников, CSV с BOM/кавычками/многострочными значениями/русскими заголовками, повторяющиеся номера, некорректные данные, защита экспорта от формул, повторный импорт списка вин, проверка резервных копий и черновиков, безопасные идентификаторы, даты и возраст.
- Сквозной тест в Chromium: создание сета, импорт трёх вин, личная оценка 100, повторная 88, восстановление черновика после перезагрузки, создание второго оценщика, слепая групповая сессия, результат двух участников 94, выгрузка CSV, история четырёх оценок, сравнение урожаев, сохранение и восстановление JSON, отсутствие горизонтального переполнения на телефоне и переход фокуса пультом.
- Дополнительный тест управления коллекцией: ручной ввод покупного вина, цена с копейками, фото из галереи, изменение карточки, повторное использование одной карточки в двух сетах без дубликата, изменение номера образца, классический лист, открытая дегустация задним числом и общая история.
- Снимки интерфейса при ширине 390, 1440 и 1920 CSS-пикселей. Ошибок JavaScript в сквозном тесте нет.
- CSV из папки samples успешно разобран; четыре образца, включая игристое вино.
- Нативный код скомпилирован против Android SDK 35 и переведён D8 в DEX с min API 26.
- APK выровнен zipalign. apksigner подтвердил схемы подписи v2 и v3. Все ресурсы, TV launcher и min/target SDK проверяются по собранному манифесту.

## Границы проверки

Попытка нативного запуска в Android 11 / API 30 с программной эмуляцией без KVM не дала завершённой проверки: системная загрузка эмулятора не завершилась, PackageManager ещё не был готов к установке. Успешная установка и запуск APK на Android в этой среде не подтверждены.

Браузерные тесты проверяют тот же код интерфейса и модели, который упакован в APK. Они не заменяют проверку нативных системных диалогов Android. Физические телефоны, камеры и Android TV в этой среде не подключены; выбор файлов, камера и экранная клавиатура зависят от установленных приложений на целевом устройстве. Для окончательной приёмки установите APK на свой телефон и телевизор, импортируйте samples/wines.csv, сохраните оценку, перезапустите приложение, экспортируйте CSV и JSON, проверьте фото и пульт.

Основной путь сборки scripts/build-apk.sh проверен. Конфигурация Android Studio/Gradle включена для разработки, отдельная Gradle-сборка в этой среде не выполнялась.
